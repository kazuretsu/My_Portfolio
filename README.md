## About this site

Built with **React + TypeScript + Vite**, **Tailwind CSS v4**, and **shadcn/ui** (Base UI primitives). Deployed to GitHub Pages on a custom domain.

### Local development

```bash
bun install
bun dev          # start the dev server
bun run build    # production build
bun run preview  # preview the build
```

### Deployment

Pushing to the `react` branch triggers the GitHub Actions workflow
([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)), which builds the
site and publishes it to GitHub Pages at [kazuretsu.dev](https://kazuretsu.dev).
